# セクション文脈と演技指示：P0〜P2実行結果

2026-09-23。[改善計画](scene-author-8b-input-recovery-plan-2026-09-23.md)に基づく実装と短区間推論の記録。
開始前の復帰点は`01cfc6c`。既定profileや従来Planner経路を昇格・置換していない。

## 結論

**セクション文脈・ユーザー候補の入力経路は実装したが、8Bの身体振付は十分には改善しなかった。**
新指示だけ、文脈だけ、両方のいずれにも、安定した身体フレーズへの転換を確認できない。
別seedでは脚の動きが増えた例がある一方、前傾、胸前の手、単純な開腕と反復が残る。

これは「歌詞文脈が不要」又は「8Bでは不可能」という結論ではない。今回の二Sceneと二seedでは、
**文脈供給と短い日本語指示の変更だけで解決したとは言えない**、という判定である。
品質条件を満たさないため、P3の本番三段統合比較・H3比較へ進めない。追加の監査LLMも導入しない。

## 実装したもの

### P0：原文を失わない入力

- [section_context.py](../../core/planner/section_context.py)で全Templateの歌詞を出現順に集め、現在Sceneが属するセクション区間を取得する。
- 当該Sceneの`original_lyrics`には原文・歌詞時刻・元行位置を保持。`section_lyric_context`を意味理解専用として別に渡す。
- 異なる区間の同名CHORUSや同文歌詞を文字列だけで統合しない。セクション境界をまたぐSceneへは両区間を渡す。
- Templateは元見出しIDを持たないため、実装が識別できるのは連続ラベル区間。**隣接する同名見出しは区別できない**。`boundary_source=template_label_run`として制限を明示する。原歌詞にない節や語句は補作しない。
- 演出候補を出来事担当だけでなく演技担当にも直接渡す。CameraとH3共通promptへは候補一覧を配布しない。
- 環境・照明はA/B/Cで共有する。人物演技担当へ詳しいCamera profileを混ぜない。
- 予算超過時はScene全体をslot分割する前に、遠いセクション文脈を半分ずつ減らして再計測する。当該Scene歌詞、作者固定文、候補原文は残す。削減はINFOと`coverage=partial`／省略行数で確認できる。
- cache識別はPlanner v82へ更新した。

### P1：振付家としての依頼

演技担当へ、部位名を羅列した姿勢記述ではなく、感情のため→主動作→反動又は解放→異なる終わりの姿を考えるよう依頼した。
外部出来事は身体演技の全文命令ではないこと、出来事なしでも演技が成立することを明記した。
全部位を毎Shotで動かす義務や語彙検査は追加していない。

出来事の開始を名詞一語の発声Shotへ機械的に限定する文も除き、一続きの文意に沿う予告・余韻を許す。
作者固定の演出位置は保持する。これらはオプトイン経路での試験用変更であり、創作品質の合格を意味しない。

Scene 5の外部出来事は`なし`、Scene 9は「人物の周囲の空間に複数の狐火が現れる。」でShot 2指定。
四条件で同一にし、出来事担当の誤分類を比較へ混ぜない。人物・Motion profile・尺・Shot枠も同一。
候補は空なので、**今回の実LLM比較は候補による改善を検証していない**。

top_p 0.9、repetition_penalty 1.05。実効seedをpayload非依存で固定した。
旧動画のtemperature 0.1等を再現した試験ではなく、今回の四条件間を統制した試験である。

- seed 1：2 Scene×4条件＝8呼出し。[manifest](../assets/research/section-performance-2026-09-23/seed1/manifest.json)
- seed 2：基準Aと新条件D、2 Scene×2条件＝4呼出し。[manifest](../assets/research/section-performance-2026-09-23/seed2/manifest.json)

計14呼出しの計測時間合計は約78.8秒（モデルload等を除く）。入力計測は741〜1,577 token。
コンテキスト回復は不要だった。全system文、payload、応答、実効設定、時間をJSONへ保存。
四条件比較はsystem・payloadのSHA-256も保存した。

試験のセクション全文は元歌詞ファイルから取り、局所歌詞が一意の連続箇所に一致することを検査する。
元見出しがあるため試験入力の`boundary_source`は`original_heading`である。
実装のTemplate連続区間とは出所が異なるが、この対象曲のVerse／Pre-Chorus／Chorusは対応する。
単独切り出しのため前Scene終端や詳細な人物・舞台の再現はなく、全曲実運用のA/Bではない。
